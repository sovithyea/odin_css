# Odin Landing Page

A responsive landing page built with HTML and CSS as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

##  Live Demo

>https://sovithyea.github.io/odin_css/


## About

This project is a static landing page that demonstrates foundational HTML and CSS skills. It was built following The Odin Project's HTML Foundations / CSS Foundations course and covers common layout patterns found in real-world web pages.

##  Project Structure

```
odin_css/
├── index.html      
└── css/
    └── styles.css  
```

## Sections

The page is composed of the following sections:

- **Header** — Logo and navigation links
- **Hero** — Headline, subtext, and a call-to-action button alongside a placeholder image
- **Info Cards** — A row of four cards with images and descriptive text
- **Quote** — A highlighted quote block
- **Call to Action** — A prompt encouraging users to get started
- **Footer** — Copyright notice

## Built With

- HTML5
- CSS3 (Flexbox)

## Concepts Practiced

- Semantic HTML structure
- CSS Flexbox for layout
- Styling buttons and links
- Organizing styles with external stylesheets
- Section-based page layout

## Getting Started

No build tools needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/sovithyea/odin_css.git
cd odin_css
open index.html
```
